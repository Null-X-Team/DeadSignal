# Dead Signal

Null X Interactive corridor survival. **Pure HTML, CSS, and JavaScript** — open `index.html` in a browser. No install, no build.

## Play

Double-click `index.html`, or drag it into a browser tab.

Or enable **GitHub Pages**: Settings → Pages → Deploy from branch `main` / root.

- **A / D** — walk left and right (faces upright)
- **Mouse** — aim and fire
- **R** — reload
- **Space** — pulse kick
- **E** — armory after a wave
- **1–4** — switch owned guns
