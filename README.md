# Dead Signal

Pure HTML/CSS/JS. No install. No build. No Codespaces.

## Play

Open **https://null-x-team.github.io/DeadSignal/**

Or download this repo and open `index.html` in any browser.

## Controls

- **A / D** walk left / right
- **Mouse** aim and fire
- **R** reload
- **Space** pulse kick
- **E** armory after a wave
- **1-4** switch guns

Everything lives in one file: `index.html`.
